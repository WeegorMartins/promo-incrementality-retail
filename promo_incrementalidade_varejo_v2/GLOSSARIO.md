# Glossário em português

| Termo comum | Forma usada no projeto | Significado |
|---|---|---|
| uplift | aumento adicional estimado | diferença estimada além do que ocorreria sem a ação |
| baseline | referência | comportamento esperado sem a promoção |
| holdout | grupo não exposto | parcela preservada para comparação |
| pull-forward | antecipação de compra | compra futura realizada mais cedo por causa da promoção |
| feature | variável explicativa | informação usada na análise/modelo |
| outcome | resultado | métrica afetada que queremos medir |
| treatment | tratamento/exposição | ação promocional observada |
| matching | pareamento | busca de unidades comparáveis |
| fixed effects | efeitos fixos | controles para diferenças constantes entre unidades/períodos |
| event study | estudo de evento | efeitos estimados ao redor do início da promoção |
| break-even | ponto de equilíbrio | valor mínimo necessário para cobrir o custo |
| pipeline | fluxo de processamento | sequência reproduzível de etapas de dados |
| staging | preparação | camada que padroniza a fonte |
| mart | tabela analítica | tabela pronta para pergunta ou painel |
